# ittybitty shaders

72 WebGL2 shaders I wrote from scratch for [ittybitty.dev](https://ittybitty.dev). Each one is a single ES module with no dependencies. They share a small runtime that stops drawing when the canvas scrolls offscreen or the tab goes to the background, caps the pixel ratio, and shows a still frame to anyone who has asked their system for reduced motion.

You can play with every one of them, controls and all, at **[ittybitty.dev](https://ittybitty.dev)**.

## Use

Copy a shader's file into your project, along with any helpers it imports (they're listed at the top of the file). Then:

```html
<canvas style="width: 100%; height: 400px"></canvas>
<script type="module">
  import { aurora } from './shaders/aurora.js';
  const fx = aurora(document.querySelector('canvas'), { intensity: 1.4 });
  // fx.set({ speed: 0.5 }) · fx.destroy()
</script>
```

If you'd rather stay in HTML, put `ittybitty-shader.js` in the same folder and use the element:

```html
<script type="module" src="./shaders/ittybitty-shader.js"></script>
<ittybitty-shader effect="aurora" intensity="1.4"></ittybitty-shader>
```

There's a bare page for each shader in [`examples/`](examples). Browsers won't load ES modules from a `file://` address, so open them through a local server (`npx serve` is enough).
